# Generador de Contraseñas Seguras

**Integrantes:**
*   Mateo Fernando Salinas Salinas

**Objetivo del Sistema:**
Desarrollar una aplicación de escritorio que genere contraseñas seguras y aleatorias, permitiendo al usuario configurar la longitud y los tipos de caracteres (mayúsculas, minúsculas, números y símbolos) para mejorar la seguridad de sus credenciales.

**Descripción de Funcionalidades:**
*   Configuración de la longitud de la contraseña (8 a 32 caracteres).
*   Selección de los tipos de caracteres a incluir.
*   Validación de la configuración (longitud y selección de al menos un tipo).
*   Generación de contraseñas garantizando al menos un carácter de cada tipo seleccionado.
*   Visualización de la contraseña generada.
*   Copiado de la contraseña al portapapeles.
*   Interfaz gráfica intuitiva desarrollada con Tkinter.

**Tecnologías Utilizadas:**
*   Python 3
*   Tkinter (Interfaz Gráfica)
*   Git y GitHub (Control de Versiones)
